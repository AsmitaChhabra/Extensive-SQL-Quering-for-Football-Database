# Football Analytics Dashboard with SQL + Tkinter

This project presents an interactive Football Analytics Dashboard built using **Python’s Tkinter** for UI and **MySQL** as the backend database.  
It allows users to query, explore, and visualize football player and club statistics from a relational database modeled on real-world transfer data.

>  **Note:** This project was completed as part of the DTSC221 coursework (AY 2024–25) at FLAME University under the guidance of **Dr. Girija Limaye**.  
> The database design and queries are based on structured data sourced from [Transfermarkt](https://www.transfermarkt.com) and Kaggle.

---

## 📌 Project Objective

To simulate a professional football analytics window where users can:
- Search player profiles
- Analyze market value trends
- Track transfers and club history
- Evaluate top performers and aggressive players
- Compare club spending patterns

##  Skills Applied

###  **Database Design & Management**
- ER Diagram creation
- Functional dependency analysis
- Normalization to 3NF

###  **SQL**

### **Data Visualization**
- Matplotlib plots for valuation trends
- Canvas-based flowchart visuals for transfers

## User Interface Features

| Feature | Description |
|--------|-------------|
|  Top Goal Scorers | Filter by season, nationality, club |
|  Aggressive Players | View by yellow/red cards |
|  Player Information | Position, birth details, current club |
|  Transfer Flowchart | Visual transfer history |
|  Valuation Trends | Line chart of market value over time |
|  Club Spending | Transfer balance: spending vs revenue |
|  Oldest Players | Sorted list of veteran players |
|  Club History | Number of clubs played for per player |
